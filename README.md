# Документация проекта Geometric Lib

## Общее описание решения

Библиотека для расчета площадей и периметров геометрических фигур. В рамках лабораторной работы №4 для библиотеки написаны автоматические unit-тесты на модуле `unittest`.

## Описание функций

### `square.py`

#### `area(a)`

- **Описание:** Вычисляет площадь квадрата.
- **Параметры:** `a` (int/float) — длина стороны квадрата.
- **Возвращает:** int/float — площадь квадрата.
- **Пример вызова:** `area(5)` вернет `25`.

#### `perimeter(a)`

- **Описание:** Вычисляет периметр квадрата.
- **Параметры:** `a` (int/float) — длина стороны квадрата.
- **Возвращает:** int/float — периметр квадрата.
- **Пример вызова:** `perimeter(5)` вернет `20`.

### `circle.py`

#### `area(r)`

- **Описание:** Вычисляет площадь круга.
- **Параметры:** `r` (int/float) — радиус круга.
- **Возвращает:** float — площадь круга.
- **Пример вызова:** `area(3)` вернет `28.274333882308138`.

#### `perimeter(r)`

- **Описание:** Вычисляет длину окружности (периметр).
- **Параметры:** `r` (int/float) — радиус круга.
- **Возвращает:** float — длина окружности.
- **Пример вызова:** `perimeter(3)` вернет `18.84955592153876`.

### `rectangle.py`

#### `area(a, b)`

- **Описание:** Вычисляет площадь прямоугольника.
- **Параметры:** `a`, `b` (int/float) — длины сторон прямоугольника.
- **Возвращает:** int/float — площадь прямоугольника.
- **Пример вызова:** `area(3, 4)` вернет `12`.

#### `perimeter(a, b)`

- **Описание:** Вычисляет периметр прямоугольника.
- **Параметры:** `a`, `b` (int/float) — длины сторон прямоугольника.
- **Возвращает:** int/float — периметр прямоугольника.
- **Пример вызова:** `perimeter(3, 4)` вернет `14`.

## План тестирования

### Цели и задачи тестирования

Проверить, что функции библиотеки Geometric Lib правильно считают площади и периметры квадрата, круга и прямоугольника. Для этого написаны автоматические unit-тесты, которые позволяют проверить правильность работы функций.

### Описание тестируемого продукта

Библиотека для расчета площадей и периметров геометрических фигур. Модули `square.py` и `circle.py` содержат по две функции, `area` и `perimeter`, которые принимают сторону квадрата или радиус круга. Модуль `rectangle.py` содержит те же функции для прямоугольника с двумя сторонами.

### Область тестирования

Функции `area` и `perimeter` из модулей `square.py`, `circle.py` и `rectangle.py`.

### Стратегия тестирования

Сначала выполняется ручное тестирование: для каждого набора входных данных ответ считается вручную и сравнивается с результатом программы. Затем те же проверки автоматизируются с помощью `unittest` (функциональное unit-тестирование). Проверяются обычные значения, ноль, дробные числа и особые случаи. Для круга используется сравнение с допустимой погрешностью (`assertAlmostEqual`), поскольку в вычислениях применяется число π.

### Критерии приемки

Все 18 тестов должны завершиться успешно, результаты должны совпадать с ручным расчетом.

### Ожидаемые результаты

При запуске команды `python -m unittest -v test_geometric_lib.py` выводится сообщение о 18 пройденных тестах и статус `OK`. Если какой-то тест не проходит, дефект фиксируется в протоколе тестирования: входные данные, ожидаемый и полученный результат.

## Запуск тестов

```
python -m unittest -v test_geometric_lib.py
```
